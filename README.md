# ♥ Coração: papel de parede vivo para Windows

Um coração 3D que bate no ritmo do computador. Com o PC tranquilo ele bate devagar; quando o PC trabalha pesado, acelera até ~160 bpm. Embaixo corre uma faixa de eletrocardiograma (DII) batendo junto.

## Instalar (1 minuto)

1. Baixe o **[Coracao-Instalador.exe](https://github.com/samuelebnerar-web/coracao-windows/releases/latest/download/Coracao-Instalador.exe)**.
2. Dê dois cliques nele.
   - Se aparecer **"O Windows protegeu o computador"**: clique em **Mais informações** › **Executar assim mesmo**. (O aviso aparece porque o app não tem certificado pago.)
3. Pronto. O coração aparece atrás dos ícones da área de trabalho e passa a abrir sozinho junto com o Windows.

Não precisa ser administrador nem instalar mais nada.

## Ajustes

Clique no **♥ perto do relógio** (se não aparecer, clique na setinha **^** da bandeja):

- **Ritmo**: acompanhar o computador (padrão) ou um ritmo fixo (sinusal, FA, flutter, TV, FV…)
- **Aparência**: Translúcido, Luz ou Anatômico
- **Energia**: Econômica se o notebook esquentar
- **Girar devagar**, **Mostrar o monitor (ECG)**, **Em todos os monitores**
- **Pausar**, **Iniciar com o Windows**, **Fechar o Coração**

## Tirar

Configurações › Aplicativos › **Coração** › Desinstalar.
